# ColonySim

ColonySim — проект симулятора колонии. Валт хранит материалы проектирования, репозиторий продукта — производственную документацию, а прототипы можно открывать и собирать по отдельности.

| Репозиторий | Содержимое |
| --- | --- |
| [ColonySim-Vault](https://github.com/ilyasazazaz/ColonySim-Vault) | Валт Obsidian, заметки, исследования и правила работы с ними |
| [ColonySim-Product](https://github.com/ilyasazazaz/ColonySim-Product) | Производственные материалы и архитектурные записки |
| [ColonySim-Simple-Colony](https://github.com/ilyasazazaz/ColonySim-Simple-Colony) | Unity-прототип графовой карты, экономики и управления колонией |
| [ColonySim-Pawn-Stories](https://github.com/ilyasazazaz/ColonySim-Pawn-Stories) | Unity-прототип самостоятельных решений пешек и истории группы |

Для работы с заметками клонируйте валт и откройте папку `ObsidianVault/` в Obsidian. Для запуска прототипа клонируйте его репозиторий и добавьте корень клона в Unity Hub. Версия Unity и инструкции запуска указаны в README прототипа.

[Исходный репозиторий ColonySim](https://github.com/ilyasazazaz/ColonySim) хранит исходные ветки и обсуждения. Связь старых и новых SHA заметок описана в README валта.
